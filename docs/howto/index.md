# How-to guides

Short, task-oriented pages: each one answers a single question and links to the reference for the details. If you are new to Nox, start with the [tutorial](../tutorial/index.md) instead.

| I want to… | Guide |
|---|---|
| keep my executables small | [Reduce binary size](binary-size.md) |

Looking for something else? The [language reference](../language/index.md) says what Nox guarantees, the [standard library](../stdlib/index.md) lists every module, and the [FAQ](../reference/faq.md) answers common questions.
