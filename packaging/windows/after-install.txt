Nox is installed.

Open a NEW terminal (so the updated PATH is picked up) and run:

    noxc version

noxc needs a C toolchain to link the programs it builds. If you do not have one, the easiest is Zig:

    winget install zig.zig

or install MinGW-w64 (for example through MSYS2). Without either, noxc cannot link; with Zig it uses the default LLVM back end.

Docs: https://noxlang.com/docs/
Update: download the newer installer from https://github.com/mburakmmm/nox-lang/releases (noxc upgrade also works for installs in your user profile).
