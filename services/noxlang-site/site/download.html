Install

Download Nox

One archive per platform: the compiler, the language server, the runtime and the standard library. Pick your system — we preselect the one you are on.

Nox for macOS

latest
Download for Apple silicon Intel Mac: build from source

Prebuilt for Apple silicon (M-series). Intel Macs build from source in a couple of minutes with Zig.

Or install from a terminal

$curl -fsSL https://noxlang.com/install.sh | sh
$brew install mburakmmm/nox/noxc

Minimum requirements

  • Apple silicon Mac (arm64)
  • Xcode Command Line Tools (xcode-select --install) for linking
  • Optional: clang or zig for the default LLVM back end — without them Nox falls back to the bundled QBE back end

Nox for Windows

latest
Download the installer (x64) Portable .zip

Installs for your user by default — no administrator rights — and adds noxc to your PATH. The installer is not code-signed yet, so SmartScreen may ask once: More info → Run anyway, or compare the .sha256 file.

Or install from PowerShell

PS>irm https://noxlang.com/install.ps1 | iex

Minimum requirements

  • Windows 10 or 11, 64-bit (x86-64; Windows on ARM runs it through emulation)
  • Zig (winget install zig.zig) or MinGW-w64 on PATH for linking

Being published to the AUR — build it from this repository meanwhile.

Homebrew

Works on Linux too.

$brew install mburakmmm/nox/noxc

Or one line

$curl -fsSL https://noxlang.com/install.sh | sh

Minimum requirements

  • x86-64 or aarch64 Linux
  • gcc (or another cc) for linking — build-essential on Debian and Ubuntu
  • Optional: clang or zig for the default LLVM back end; the QBE back end needs neither

In the browser

Beta
Open the Playground Embed the compiler

The whole compiler runs in your browser as WebAssembly — your code never leaves the page. Nox programs also compile to WebAssembly modules for WASI runtimes and for any host that speaks nox_host.

Compile to WebAssembly

$noxc build --target wasm32-wasi main.nox -o main.wasm
$noxc run --target wasm32-freestanding-asyncify main.nox
Browser compiler bundle WebAssembly guide

Requirements

  • A current browser (Chrome, Edge, Firefox or Safari) for the Playground
  • Node 22 or newer — or any WASI runtime — to run .wasm output outside the browser
