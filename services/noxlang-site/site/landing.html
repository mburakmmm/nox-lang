Nox 2.0 — native without the ownership noise

A statically typed language with Python’s syntax, compiled ahead of time to native code.

Memory is managed for you — there is no borrow checker, no lifetime syntax and no free. Write what you mean; the compiler works out the rest.

Why Nox

Familiar to write. Honest about the machine.

Python’s syntax, checked at compile time

Every parameter, variable and return value has a type the compiler verifies — no Any, no surprises at run time. If you can read Python, you can read Nox.

Memory without the vocabulary

Values are freed at their last use when the compiler can prove it is safe, and reference-counted when it cannot — silently, never as an error you have to fix.

Native, and parallel by default

Compiled through LLVM (or the small QBE back end) into a single executable. Tasks and channels run on a work-stealing scheduler across every core.

In practice

A small language that writes real programs.

Every example here is compiled and run when this site is built.

Build on Nox

Three APIs, one stability promise.

Nox 2.0 draws a clear line around what stays compatible for the whole 2.x series — and what is free to change.

Read the API overview

Plugin API manifest · lifecycle

Describe a native plugin in nox-plugin.json and load it at run time with nox.plugin — versioned, with declared capabilities.

NNI native C ABI

A stable C interface with opaque, generation-checked handles. Native code never sees a pointer into Nox’s heap.

NAPI source contract

The Nox API itself: the language surface and standard library that frameworks and libraries program against.

Toolchain

One command for everything.

Build, run, test, format and explain code; manage packages; upgrade the compiler itself. A language server and editor support come in the box.

Explore noxc 
$ noxc init hello && cd hello
$ noxc run main.nox
$ noxc build -o hello main.nox
$ noxc test
$ noxc explain main.nox   # where each value lives, and why
$ noxc search http         # query the noxpkg registry
$ noxc upgrade              # update the compiler
